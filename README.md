# পরীক্ষা বন্টন তালিকা | جدول توزيع الامتحانات

মাদ্রাসার পরীক্ষায় **কোন কিতাবের পরীক্ষা কোন উস্তাদের কাছে হবে**, তা ঠিক করার একটি ওয়েব টুল। একটিমাত্র HTML ফাইল, কোনো সার্ভার বা ডাটাবেস লাগে না। ইন্টারফেস আরবিতে।

*A single-file, Arabic-interface web tool for assigning exam examiners (ustads) to books by class and day. No server or database required.*

## কী কাজ করে

- **ডানে বন্টন ছক:** সারিতে দিন, কলামে জামাত। প্রতিটি ঘরে কিতাবের নাম লিখুন।
- **বামে উস্তাদের তালিকা:** উস্তাদের নামের পাশে কিতাবের নাম লিখলেই ছকে ঐ কিতাবের নিচে উস্তাদের নাম বসে যায়। মুছলে সরে যায়।
- **একই দিনে দুই পরীক্ষা নয়:** কোনো উস্তাদের একই দিনে দ্বিতীয় কিতাব দিলে তা বসে না। ঘর লাল হয় এবং সতর্কবার্তা আসে।
- **হোভার:** বামে উস্তাদের নামের ওপর মাউস রাখলে ডানে তাঁর সব নাম লাল হয়।
- **সম্পাদনাযোগ্য হেডার:** বিসমিল্লাহ, মাদ্রাসার নাম, শিরোনাম ও পরীক্ষার নাম-সন বদলানো যায়।
- **ঘরের মাপ:** কলাম ও সারি টেনে ছোট-বড় করা যায় (এক্সেলের মতো), দুই পাশেই।
- **সারি-কলাম বাড়ানো/কমানো:** দিন, জামাত, উস্তাদ ও কিতাবের কলাম ফাইলের ভেতরেই বাড়ানো-কমানো যায়।
- **একাধিক প্রজেক্ট:** নতুন প্রজেক্ট, হুবহু কপি (ডুপ্লিকেট), প্রজেক্ট বদলানো ও মুছে ফেলা।

## আউটপুট

| বাটন | ফল |
|---|---|
| PDF — الجدول (أفقي) | বন্টন ছক, A4 ল্যান্ডস্কেপ |
| PDF — قائمة الأساتذة (عمودي) | উস্তাদ-তালিকা, A4 পোর্ট্রেট |
| تنزيل Word | `.docx`: ছক (ল্যান্ডস্কেপ) + উস্তাদ-তালিকা (পোর্ট্রেট) |
| بطاقات الأساتذة (Word) | প্রতি উস্তাদের জন্য কার্ড, A4 পোর্ট্রেটে প্রতি পৃষ্ঠায় ২টি। টীকা ও তারিখ সম্পাদনাযোগ্য |
| أساتذة كل يوم (Word) | কোন দিন কোন কোন উস্তাদের পরীক্ষা, তাঁদের কিতাবসহ |
| تنزيل Excel | `.xlsx`, দুটি শিটে |
| نسخ احتياطي للبيانات | সব প্রজেক্টের ডেটা টেক্সট হিসেবে কপি / পুনরুদ্ধার |

PDF বাটন ব্রাউজারের প্রিন্ট ডায়ালগ খোলে। সেখানে **Save as PDF** বেছে নিন, "Background graphics" টিক দিন এবং "Headers and footers" বন্ধ রাখুন। Chrome সুপারিশ করা হয়।

## ব্যবহার

1. `index.html` ব্রাউজারে খুলুন (ডাবল ক্লিক, বা নিচের মতো ডিপ্লয় করে)।
2. "مشروع جديد" দিয়ে দিন, জামাত, উস্তাদ ও কিতাব-কলামের সংখ্যা ঠিক করুন।
3. ডানের ছকে কিতাব লিখুন, তারপর বামে উস্তাদের পাশে কিতাবের নাম লিখুন। কিতাবের নাম দুই জায়গায় **হুবহু মিলতে হবে** (হরকত ও ي/ی, ك/ک-এর মতো সাধারণ ভেদ ধরা হয়)।
4. একই নামের কিতাব একাধিক জামাতে থাকলে ভিন্ন নাম দিন (যেমন "হিদায়া ২", "হিদায়া ৩"), নইলে উস্তাদ সবগুলোতে বসবেন।
5. কাজ শেষে প্রয়োজনীয় আউটপুট নামান।

## GitHub Pages-এ ডিপ্লয়

1. নতুন রিপোজিটরি খুলুন এবং এই ফাইলগুলো মূল ফোল্ডারে আপলোড করুন (`index.html`, `README.md`)।
2. **Settings → Pages → Source:** "Deploy from a branch", branch `main`, folder `/ (root)`, তারপর Save।
3. কয়েক মিনিট পর `https://<ইউজারনেম>.github.io/<রিপোজিটরি>/` ঠিকানায় চালু হবে।

আর কিছু (বিল্ড, `package.json` ইত্যাদি) লাগে না।

## ডেটা ও গোপনীয়তা

- সব ডেটা ব্যবহারকারীর **নিজের ব্রাউজারে** (`localStorage`) থাকে। কোথাও পাঠানো হয় না।
- প্রতিটি ঠিকানা ও ব্রাউজারের ডেটা আলাদা। অন্য ডিভাইসে নিতে "نسخ احتياطي للبيانات" বাটন ব্যবহার করুন।
- ব্রাউজারের ডেটা মুছলে বা ব্রাউজার বদলালে ডেটা হারাতে পারে, তাই নিয়মিত ব্যাকআপ রাখুন।
- এই রিপোজিটরির `index.html`-এ কোনো ব্যক্তিগত তথ্য বা নমুনা ডেটা নেই।
- "حفظ نسخة HTML بالبيانات" বাটনে বানানো ফাইলে আপনার ডেটা ঢুকে যায়, তাই সেই ফাইল পাবলিক রিপোজিটরিতে দেবেন না।

## সীমাবদ্ধতা

- ছকের ঘরে উস্তাদের নাম সংক্ষেপে দেখায় ("ألاستاذ", "مولانا", "المحترم" ইত্যাদি বাদ দিয়ে)। উস্তাদ-তালিকায় পুরো নাম থাকে।
- বিতাকা (কার্ড) শুধু সেই উস্তাদদের হয়, যাঁদের অন্তত একটি পরীক্ষা আছে।
- Word ফাইল LibreOffice-এ যাচাই করা হয়েছে; Microsoft Word-এ ছোটখাটো পার্থক্য হতে পারে।
- ইন্টারফেস শুধু আরবিতে।
